# Anvionix Labs brand

One brand on every page: Palette C, Charcoal + Burnt Orange. Tokens live in
[`brand/tokens.css`](brand/tokens.css) and [`brand/tokens.json`](brand/tokens.json); the site maps them
onto its semantic tokens in [`app/globals.css`](app/globals.css).

## Logo

The official logo files are in [`public/brand/logo/`](public/brand/logo/) and are served at
`https://anvionixlabs.com/brand/logo/<file>`. Use them exactly as delivered: never redraw, retrace or
re-export them by hand. The A/X monogram is the only symbol.

| File | What it is | Use it for |
|---|---|---|
| `anvionix-ax-lockup-light.svg` | Mark, divider, ANVIONIX / LABS; charcoal with burnt orange | Primary logo on light backgrounds: site header and footer, documents |
| `anvionix-ax-lockup-dark.svg` | The same in white with burnt orange | Primary logo on charcoal or dark backgrounds |
| `anvionix-ax-lockup-mono-charcoal.svg` | One colour, charcoal | Single-colour print, embossing, fax-grade output |
| `anvionix-ax-lockup-mono-white.svg` | One colour, white | On photos or any dark background where two colours won't hold |
| `anvionix-ax-lockup-mono-orange.svg` | One colour, burnt orange | Large sizes on Warm White or Charcoal only (3.5:1 / 4.2:1) |
| `anvionix-ax-mark-light.svg` / `-dark.svg` | The A/X monogram alone | Where the lockup won't fit (narrow headers, small UI) |
| `anvionix-wordmark-light.svg` / `-dark.svg` | ANVIONIX / LABS alone | Where the mark already appears nearby |
| `anvionix-ax-icon.svg` | Charcoal rounded tile, white A, orange X | App icons, social avatars, JSON-LD logo |
| `anvionix-ax-icon-light.svg` | The tile on Warm White | App icon where a light tile is needed |
| `favicon-16.svg`, `favicon-32.svg` | Tiles drawn for 16 and 32 px | Browser favicons |
| `board.svg` | The full brand board | Reference only |

### On the site

- Header: the lockup, 28 px high, light or dark to follow the system scheme; below 360 px wide,
  the mark alone (24 px). Footer: the lockup, 36 px high. Engagement slip: the lockup, 24 px.
  Component: [`components/site/logo.tsx`](components/site/logo.tsx); paths in `LOGO` in `data/site.ts`.
- Icons, generated by `node brand/build-icons.mjs` from the files above: `app/favicon.ico` (16, 32,
  48), `app/icon.svg` (favicon-32), `app/apple-icon.png` (180, full-bleed), `public/icons/icon-192.png`,
  `icon-512.png`, `icon-maskable-512.png`, and the share image `public/og.png` (1200 x 630, the lockup
  on Warm White). Manifest: `public/site.webmanifest` (Charcoal theme and background).
- JSON-LD `Organization.logo`: `/icons/icon-512.png` (PNG for compatibility).

### Clear space and minimum size

- Clear space on every side: half the height of the A/X mark. Nothing (text, edges, other logos)
  enters it.
- Minimum sizes: lockup 120 px wide on screen; mark 24 px high; icon 32 px. The favicon at 16 px
  is borderline legible, so use `favicon-16.svg` there and prefer 32 px wherever the platform allows.

### Don'ts

- Don't redraw, retrace, re-space or re-typeset the logo, or rebuild the wordmark from a font.
- Don't recolour it outside the supplied variants, or swap which stroke is orange.
- Don't stretch, skew, rotate, outline, add shadows, gradients or effects.
- Don't put the light lockup on dark backgrounds, or the dark one on light backgrounds.
- Don't place it on busy photos without the white one-colour version and enough contrast.
- Don't use the orange one-colour lockup small or on Sand.
- Don't separate the mark and wordmark into a new arrangement; use the supplied lockup, mark or
  wordmark files.

## Palette

| Name | Hex | Role |
|---|---|---|
| Charcoal | `#202124` | Primary: text on light, background in dark mode and the closing band |
| Graphite | `#45464A` | Secondary: body text on light, secondary surfaces |
| Burnt Orange | `#C56A3A` | Accent: fills, borders, rules, focus rings, large display |
| Sand | `#E4A47E` | Highlight: text highlights, accent text on charcoal |
| Warm White | `#F7F5F2` | Background (light), text on charcoal |

Derived shades, for text that has to pass WCAG AA:

| Name | Hex | Use |
|---|---|---|
| Burnt Orange Deep | `#A9532A` | Accent-coloured text, and orange buttons or chips that carry text, on light |
| Muted | `#6B6C70` | Tertiary text (labels, captions) on light |
| Sheet dark | `#2A2B2F` | Raised surfaces (cards, inputs) on charcoal |
| Ink 2 dark | `#CFCDC8` | Secondary text on charcoal |
| Muted dark | `#A3A4A8` | Tertiary text on charcoal |

Functional colours, never decoration: green `#1D7A4F` / `#5FD39A` (dark) for "live" status, red
`#B3261E` / `#FF8A7A` (dark) for form errors.

### Contrast (WCAG 2.1)

AA needs 4.5:1 for body text and 3:1 for large text (24px, or 18.66px bold) and UI parts.

| Text | Background | Ratio | Result |
|---|---|---|---|
| Charcoal | Warm White | 14.79:1 | AAA |
| Charcoal | White | 16.10:1 | AAA |
| Graphite | Warm White | 8.66:1 | AAA |
| Muted `#6B6C70` | Warm White | 4.82:1 | AA |
| Muted `#6B6C70` | White | 5.24:1 | AA |
| **Burnt Orange** | **Warm White** | **3.51:1** | **Large text and UI only** |
| Burnt Orange Deep | Warm White | 4.88:1 | AA |
| Burnt Orange Deep | White | 5.31:1 | AA |
| **White** | **Burnt Orange** | **3.82:1** | **Large text only** |
| **Charcoal** | **Burnt Orange** | **4.21:1** | **Large text only** |
| White | Burnt Orange Deep | 5.31:1 | AA |
| **Sand** | **Warm White** | **1.95:1** | **Never for text** |
| Charcoal | Sand | 7.60:1 | AAA |
| Red `#B3261E` | Warm White | 6.01:1 | AA |
| Green `#1D7A4F` | Warm White | 4.89:1 | AA |
| Warm White | Charcoal | 14.79:1 | AAA |
| Ink 2 dark `#CFCDC8` | Charcoal | 10.13:1 | AAA |
| Muted dark `#A3A4A8` | Charcoal | 6.46:1 | AA |
| Muted dark `#A3A4A8` | Sheet dark | 5.68:1 | AA |
| Sand | Charcoal | 7.60:1 | AAA |
| Sand | Sheet dark | 6.67:1 | AA |
| **Burnt Orange** | **Charcoal** | **4.21:1** | **Large text and UI only** |
| **Graphite** | **Charcoal** | **1.71:1** | **Never for text** |
| Red `#FF8A7A` | Charcoal | 7.03:1 | AAA |
| Warm White | Graphite | 8.66:1 | AAA |

Restricted pairs, in short:

- Burnt Orange is never body text on Warm White, White or Charcoal. Use Burnt Orange Deep on light
  and Sand on dark.
- A Burnt Orange button can't carry normal-size text in white or charcoal. Buttons that carry text
  use Burnt Orange Deep with white text (light) or Sand with charcoal text (dark).
- Sand on light, and Graphite on Charcoal, are decoration only.

## Type

The site sets type with Geist (sans), Geist Mono and Instrument Serif, all OFL, loaded through
`next/font/google`. The logo wordmark comes as outlines inside the logo files, so it never
depends on a webfont.

## Do

- Keep one palette on every page; pages differ by layout and motion, not by colour scheme.
- Use Burnt Orange sparingly: one accent per view, on rules, dots, focus rings and large display.
- Use `--accent-strong` for any accent-coloured text.
- Check new text pairs against the table above, in light and dark.

## Don't

- Don't add per-page colour schemes or new hues.
- Don't put normal-size text in Burnt Orange, or on a Burnt Orange fill.
